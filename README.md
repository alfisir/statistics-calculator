# Statistics Calculator

Модуль на Python для вычисления базовых статистических показателей (минимум, максимум и среднее арифметическое) для списка чисел.

## Структура проекта

* `statistics.py` — основной модуль с реализацией функции `calculate_statistics`.
* `test_statistics.py` — набор модульных тестов (`unittest`).


### Прямой запуск модуля

В файле `statistics.py` предусмотрен блок `if __name__ == "__main__":`, который выполняет тестовый расчет для списка ``:


### Обработка исключений

При передаче пустого списка функция выбрасывает `ValueError`:

```python
calculate_statistics([])
# ValueError: Список не должен быть пустым
```

## Тестирование

Покрытие тестами (`StatisticsTestCase`) проверяет следующие сценарии:
* положительные числа (`test_normal_numbers`)
* отрицательные числа (`test_negative_numbers`)
* список из одного элемента (`test_single_number`)
* список из одинаковых элементов (`test_same_numbers`)
* выброс `ValueError` на пустом списке (`test_empty_list`)
